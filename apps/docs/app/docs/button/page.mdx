import { Button } from "@material/ui";

# Button

Buttons allow users to take actions, and make choices, with a single tap.

## Usage

```tsx
import { Button } from "@material/ui";

export default function Page() {
  return <Button>Click me</Button>;
}
```

## Variants

### Filled (Default)

The filled button is the most prominent button.

<div className="p-4 border rounded-lg flex gap-4 my-4 bg-white dark:bg-zinc-900 border-zinc-200 dark:border-zinc-800">
  <Button variant="filled">Filled</Button>
  <Button variant="filled" disabled>Disabled</Button>
</div>

### Tonal

Tonal buttons are an alternative middle ground between filled and outlined buttons.

<div className="p-4 border rounded-lg flex gap-4 my-4 bg-white dark:bg-zinc-900 border-zinc-200 dark:border-zinc-800">
  <Button variant="tonal">Tonal</Button>
  <Button variant="tonal" disabled>Disabled</Button>
</div>

### Outlined

Outlined buttons are medium-emphasis buttons. They contain actions that are important but aren't the primary action in an app.

<div className="p-4 border rounded-lg flex gap-4 my-4 bg-white dark:bg-zinc-900 border-zinc-200 dark:border-zinc-800">
  <Button variant="outlined">Outlined</Button>
  <Button variant="outlined" disabled>Disabled</Button>
</div>

### Text

Text buttons are used for the lowest priority actions, essentially just text that is clickable.

<div className="p-4 border rounded-lg flex gap-4 my-4 bg-white dark:bg-zinc-900 border-zinc-200 dark:border-zinc-800">
  <Button variant="text">Text</Button>
  <Button variant="text" disabled>Disabled</Button>
</div>
